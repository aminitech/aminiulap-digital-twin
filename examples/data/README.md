# Example data

This repository ships **code, not data** — see [DATA.md](../../DATA.md). Everything in
this folder is either open, redistributable data or a placeholder you replace.

| File | What | Source & licence |
|---|---|---|
| `newton-open_scene_manifest.json` | The demo scene: 585 building footprints, a 70×70 terrain grid, two placeholder towers | Buildings © **OpenStreetMap** contributors (**ODbL 1.0**); terrain from **AWS Terrain Tiles** (SRTM/GMTED/3DEP, public domain). Built by `fetch_open_scene.py` |
| `newton_link_metrics.csv` | 14 ray-traced link samples: path gain, RMS delay spread, path count | **Sionna RT output from this project** — a simulation result, not third-party data. Plotted in `docs/renders/link_metrics.png` |
| `newton-bbd.study.toml` | A study definition: centre, bbox, CRS, band plan | Generated by `ulap-scope init --defaults`. Parameters only, no geospatial content |
| `towers.template.json` | **Placeholder** site list you edit | Not data — a template |

**Not here, deliberately:** the Barbados Geoportal layers (building footprints with
LiDAR heights, the LiDAR DTM) behind `docs/renders/`. They are subject to a Government
of Barbados disclosure review and are not ours to redistribute. The pipeline reads them
from `$ULAP_DATA_DIR` at run time. A test (`test_no_geoportal_derived_scene_is_committed`)
fails if a scene in the Barbados National Grid reappears in this folder.

## Build a scene for your own area

```bash
python fetch_open_scene.py                                   # the pilot study area
python fetch_open_scene.py --lon 36.8219 --lat -1.2921 --name nairobi-cbd
python fetch_open_scene.py --half-width 1500 --zoom 15 --towers my_sites.json
```

It fetches OSM footprints via Overpass and elevation from AWS terrain tiles, projects
everything into the correct UTM zone for your longitude, and writes a manifest in the
same shape `ulap-scope preprocess` produces — so the notebooks and apps consume it
unchanged. Every layer's source, licence and heuristic is recorded in the manifest's
`provenance` block and printed by `scene.sources()`.

Overpass is a free shared service and rate-limits by IP. If it refuses you, export the
area from <https://overpass-turbo.eu> and pass it with `--osm-json`.

### What open data costs you

- **Heights.** OSM rarely tags building heights. Where `height` or `building:levels` is
  missing, the script assigns a per-type default (`DEFAULT_HEIGHTS_M`) and records
  `h_source` on every building. The pilot used measured LiDAR heights; the difference is
  visible in notebook 03's height histogram.
- **Terrain.** ~30 m posting, not a LiDAR DTM. Fine for hills, blind to embankments.
- **Towers.** No open registry of site positions and heights is bundled. Edit
  `towers.template.json`, or use a public source such as OpenCellID (CC BY-SA 4.0).

## Use your own scene instead

`load_scene()` takes the first of:

1. an explicit path — `load_scene("path/to/scene_manifest.json")`
2. `$ULAP_SCENE`
3. the bundled open-data sample

Pipeline output at `blender/scene_build/scene_manifest.json` is **not** auto-selected.
It is opt-in (`export ULAP_SCENE=...`), so results never depend on what a particular
clone happens to contain, and a licence-restricted scene is never loaded by accident.
`ulap_demo.scene.pipeline_scene_hint()` prints the exact command when such a manifest
is present.
